# Golden Dataset

هذا هو **البوابة** التي تمنع تكرار ما حدث: تحسين التطبيع بلا قياس
أدى إلى تدهور الترتيب دون أن يلاحظه أحد حتى ظهر في الاستخدام.

## القاعدة (الماستر §10)
> لا يُقبل أي تحسين جديد إلا إذا أثبت رقمياً أنه أفضل أو أوفر دون إضرار الجودة.

## كيف تبني المجموعة

ابدأ صغيراً: **20–30 سؤالاً** تغطي أنواع الاستعلام عندك.
لكل سؤال، ابحث يدوياً وسجّل `element_id` للنتائج الصحيحة فعلاً.

```jsonl
{"id":"q010","query":"...","intent":"hadith","relevant_element_ids":["uuid1","uuid2"]}
```

## الحقول

| الحقل | المعنى |
|---|---|
| `query` | نص السؤال كما يكتبه المستخدم |
| `intent` | entity / hadith / quran / bibliography / general |
| `relevant_element_ids` | معرّفات العناصر الصحيحة (أنت من يحددها) |
| `must_contain` | كلمات يجب أن تظهر في أعلى النتائج (فحص أخف) |
| `must_not_contain` | كلمات تدل على نتيجة خاطئة |
| `note` | لماذا هذا السؤال مهم |

`relevant_element_ids` الفارغ يعني أن السؤال يُقاس بـ `must_contain` فقط.
هذا مقبول كبداية، لكن القياس الحقيقي يحتاج تحكيماً بشرياً.
